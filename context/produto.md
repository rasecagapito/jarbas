# Produto

## Proposito
Registrar a visao funcional do Jarbas / S.A.M. para orientar decisoes futuras de produto, UX, arquitetura e implementacao.

## Fatos Atuais
- O projeto descreve uma plataforma multiagente chamada S.A.M. - Secure Automated Multi-Agent Platform.
- A experiencia central e um cockpit tatico/holografico para interagir com agentes por texto e voz.
- O sistema deve expor setores/agentes como PMO, Operacional, Desenvolvimento e Consultores.
- O operador humano deve conseguir enxergar logs, roteamento e decisoes do supervisor.
- O projeto possui materiais visuais, telas HTML e um documento de levantamento em `1.documentacao/levantamento/`.

## Materiais Existentes
- `1.documentacao/levantamento/textos/1-Documento de levantamento.md` - blueprint tecnico e conceitual principal.
