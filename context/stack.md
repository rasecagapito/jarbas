# Stack

## Proposito
Mapear tecnologias citadas e comandos conhecidos para orientar futuras tarefas de desenvolvimento.

## Tecnologias Citadas
- Frontend: HTML5, possivel Next.js, Tailwind CSS, Font Awesome, Three.js.
- Audio: Web Audio API, MediaRecorder, Whisper via OpenAI ou Groq.
- Orquestracao: n8n, Webhook, AI Agent, Call n8n Workflow.
- Banco: Supabase, PostgreSQL, pgvector.
- IA/RAG: embeddings `text-embedding-3-small`, busca vetorial por setor.
- Autenticacao: JWT.

## Comandos Conhecidos
Ainda nao ha package manager, scripts de build ou projeto de aplicacao detectado na raiz. A estrutura atual e documental/prototipo.
