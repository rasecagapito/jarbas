# /wrapup

Quando o usuario invocar `/wrapup`:
1. Obter data e hora atuais.
2. Identificar trabalho da sessao: arquivos criados/alterados, decisoes e pendencias.
3. Criar `memory/history/YYYY-MM-DD-HH-session.md`.
4. Criar licoes em `memory/learnings/YYYY-MM-DD-topico.md` quando houver aprendizado reutilizavel.
5. Atualizar `AGENTS.md` somente com fatos aprovados.
6. Confirmar os arquivos criados.
