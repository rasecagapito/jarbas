## Plataforma
- **IA**: Codex
- **Arquivo de identidade**: `AGENTS.md`
- **Status**: parametrizacao inicial criada em 2026-06-25

## Estrutura
| Peca | Status |
| --- | --- |
| Identidade | `AGENTS.md` criado |
| `context/` | produto, arquitetura, stack e estrutura documental |
| `memory/` | historico + licoes |
| `workers/` | arquiteto multiagente, frontend cockpit, governanca Agentic OS |
| `automation/` | evaluation + guardrails |
| comandos | wrapup + status + worker |

## Ciclo de Uso
1. Abrir o Codex na raiz do projeto.
2. Ler `AGENTS.md`.
3. Ao retomar trabalho, ler o historico mais recente em `memory/history/`.
4. Ativar workers apenas quando eles ajudarem na tarefa.
5. Usar `/wrapup` ao final de sessoes relevantes para gravar decisoes e proximos passos.
