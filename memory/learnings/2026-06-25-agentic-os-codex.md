# Licao - Agentic OS com Codex

## Contexto
O projeto esta sendo conduzido com Codex, entao o arquivo de cerebro/identidade deve ser `AGENTS.md`.

## Licoes
- Para projetos em Codex, centralizar regras operacionais em `AGENTS.md`.
- Manter `AGENTS.md` leve e referenciar `context/` para detalhes.
- Usar `memory/history/` para continuidade entre sessoes.
- Usar `memory/learnings/` para decisoes e aprendizados reutilizaveis.
- Nao alterar documentos fonte de levantamento quando a tarefa e apenas parametrizacao Agentic OS.

## Aplicacao Futura
Antes de novas implementacoes, ler `AGENTS.md`, o historico mais recente e o modulo de contexto relevante.
